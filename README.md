# disenio-sistemas-informacion-apunte

Este repositorio contiene un apunte de la materia **Diseño de Sistemas de la Información** (UTN), pensado para facilitar la cursada con contenido claro, completo y actualizado.

## Objetivo del repositorio

- Mantener un documento de estudio útil y confiable.
- Mejorar el material de forma colaborativa y ordenada.
- Cuidar la calidad de la documentación en cada actualización.

## ¿Cómo aportar?

En caso de que usted quiera aportar a la edición y actualización del PDF, tiene 2 formas:

### Cambio manual

Si decide cambiarlo de forma manual, debe además de actualizar la documentación, **actualizar el número de versión**.

### Cambio con IA

Dentro del repositorio ya existen instrucciones para la actualización del documento con IA. Cada vez que se actualice, debe **actualizar la versión**.

En ambos casos, se tiene que dejar registro de quien y que modificó.

## Reglas de colaboración (obligatorias)

- Tomar la edición con seriedad: no arruinar la documentación.
- No usar fuentes falsas o de dudosa procedencia.
- No borrar el repositorio ni su contenido.
- Mantener un trato respetuoso: no insultar.
- Si se actualiza la fuente bibliográfica, **actualizarla también en la documentación**.
